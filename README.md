Assignment 4 - Workout Tracker

https://a4-eris-ropi.onrender.com 

This project was a re-implementation of A3, a workout tracker with Svelte components. I used Svelte to handle the DOM elements from A3 to be handled by Svelte with {#await} which handles the modifications of the workout entries. So instead of manually building each time the user pressed a button with innerHTML and document.createElement, Svelte handles that itself by having promises that get executed.

Overall, I though Svelte was very useful and efficient, and simplified my code.
